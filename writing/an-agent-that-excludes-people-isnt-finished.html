An agent that excludes people isn’t finished

Voice, text, touch and sign: what accessible agentic design asks of us.

November 2026

Agentic AI promises to make software easier for everyone. It will only keep that promise if we design for everyone on purpose.

Voice includes, and voice excludes

For someone who is blind or has limited mobility, a voice agent can remove barriers that screens never solved. For someone who is Deaf, has a speech difference, or is in a loud environment, voice-only is a closed door. The answer isn’t to choose one mode. It’s to design every agent so the same experience works through voice, text, touch and sign.

Streaming answers need accessible design

When an agent writes its response in real time, a screen-reader user needs to know when it has finished. A keyboard user needs every action the agent offers to be reachable. These aren’t edge cases. They’re acceptance criteria. This builds on work by Salesforce’s digital accessibility team, whose piece AI Agents Don’t Live with Disabilities. People Do sets out how to turn disability research into testable requirements.

Sign language is arriving, and it needs care

Google has released a sign-language-to-text model that now powers sign-to-text dictation on Pixel phones, starting with American Sign Language to English. That’s a genuine shift: signing can become an input like any other. Deaf organisations have also cautioned against treating signing avatars as a replacement for human interpreters. The lesson for designers is to build these tools into our platforms, and to build them with Deaf communities, not for them.

What I ask every team

Which disabilities did you design for, and who did you test with? Does every task work without voice, without a screen, and without a mouse? When the agent changes something, how does every user know it happened?

An agent that works brilliantly for most people and fails a few isn’t finished. It’s a draft. Accessibility is where experience-first design proves itself, because it forces us to start with the person, not the technology. The pattern is written up as every mode, one experience.
