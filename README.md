# Timothy Davies: personal site

A static site with no build step. Upload the whole folder to the repository root.

- `index.html`: home page (hero, patterns, work, voice demo, writing, film, contact)
- `patterns/`: the agentic experience patterns library
- `writing/`: essays
- `now.html`, `about.html`, `accessibility.html`, `404.html`
- `motion.html`: the 54-second film, embedded on the home page
- `assets/`: shared stylesheet, accessibility script and photo
- `og/` and `og-image.png`: share images for each page
- `feed.xml`, `sitemap.xml`, `robots.txt`
- `Timothy-Davies-CV.pdf`: public CV
