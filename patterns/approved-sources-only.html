Agentic experience patterns

Approved sources only

The agent answers from a defined set of sources, and the experience makes that visible.

The problem

Open-ended answers feel impressive until one of them is wrong. For anything regulated, technical or brand-sensitive, an organisation needs to know where every answer came from, and so does the person reading it.

The pattern

Ground the agent in an approved body of knowledge, and design the answer so its source is clear. Depth adapts to the person: a short, plain first answer, with more detail when they ask for it.

Do

  • Agree the approved sources before designing the conversation
  • Show or say where an answer comes from
  • Start short and let people ask for more

Avoid

  • Filling gaps with general knowledge
  • Long first answers that bury the point
  • Hiding the source to make the agent seem cleverer

Example

  • PersonWhat changed about the engines this year?
  • AgentIn short: more electric power and new sustainable fuel. That comes from the 2026 technical regulations. Want the detail?

Where it came from

Shaped by the conversation and response logic for the Agentforce fan companion on F1.com, which answers only from approved sources and adapts its depth to each fan.
