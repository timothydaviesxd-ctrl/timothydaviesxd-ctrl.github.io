Agentic experience patterns

Design patterns for AI agents that people can trust, control and use, whoever they are and however they interact. Each one comes from live delivery.

  • Vital before visual

    Speak only what the person needs right now. Everything else waits for a screen.

  • Read back what commits

    If an action spends money, places an order or changes a record, the agent says it back and waits.

  • Three per turn

    A spoken answer never lists more than three things. If there are more, it offers them.

  • Designed refusals

    Decide what the agent won’t answer, and make saying no as well designed as saying yes.

  • Approved sources only

    The agent answers from a defined set of sources, and the experience makes that visible.

  • Explain the suggestion

    When an agent recommends something, it shows the evidence behind it.

  • Coach, don’t score

    When an agent assesses someone’s work, it points to the next improvement rather than handing down a grade.

  • Structure inside the conversation

    When the agent needs precise details, it brings a small form into the conversation instead of asking question after question.

  • Every mode, one experience

    The same experience works through voice, text, touch and sign, so nobody is shut out by the mode they use.
